## シナリオ（1 テスト関数）

1. 一時ディレクトリの状態ファイルに users `U1`、トークン `t1` の sha256 を書く
2. relay を `127.0.0.1:0` で serve（FakeSlack、固定でない実時刻）
3. 偽 agent が `tokio-tungstenite` で接続、Hello(name `mac`) → Welcome を受信
4. 署名付き `POST /slack/commands`（`/cc`、user U1、channel C1）→ 応答 JSON の options に `mac`
5. 署名付き `POST /slack/interactions`（mac 選択）→ FakeSlack に root 投稿、状態ファイルに binding
6. 署名付き `POST /slack/events`（その thread_ts への返信 `hello`、user U1）→ 偽 agent が `Inbound{text: "hello"}` を受信
7. 同じ event_id をもう一度 POST → 偽 agent に 2 通目が来ない（300ms 待つ）
8. 偽 agent が `Reply{chat_id, text: "hi"}` → FakeSlack にスレッド投稿
9. 偽 agent が `PermissionRequest{request_id: "abcde", ...}` → FakeSlack にプロンプト
10. events で `yes abcde`（user U1）→ 偽 agent が `PermissionVerdict{abcde, Allow}`
11. 偽 agent が 8000 文字（改行なし）の Reply → FakeSlack に 3 投稿
12. user U2 の返信 → 偽 agent に何も来ない
