## 公開 API

```rust
pub struct Backoff { pub initial: Duration, pub max: Duration }
pub struct Identity { pub name: String, pub host: String, pub cwd: String }
pub fn identity_from(session_name: Option<String>, host: String, cwd: &Path) -> Identity; // name default "host:dirname"
pub async fn run(
    url: String,
    token: String,
    id: Identity,
    backoff: Backoff,
    to_stdout: mpsc::Sender<serde_json::Value>,
    from_mcp: mpsc::Receiver<protocol::AgentMsg>,
);
```

## テスト（先に書く、`ws/tests.rs`）

テスト内で `tokio_tungstenite::accept_hdr_async` を使う偽 relay を `127.0.0.1:0` に立てる。

- `identity_default_name`: `session_name=None, host="mac", cwd="/a/proj"` → `mac:proj`
- `identity_explicit_name`
- `sends_bearer_and_hello_first`: ヘッダ `Authorization: Bearer t`、最初のフレームが Hello で version 1
- `inbound_becomes_channel_notification`: 偽 relay が Inbound を送ると to_stdout に `notifications/claude/channel` が届く
- `reply_forwarded_to_relay`: from_mcp に Reply を入れると偽 relay が受け取る
- `verdict_becomes_permission_notification`
- `reconnects_after_close`: 偽 relay が 1 回目の接続を閉じると、`Backoff{initial: 50ms}` で 2 回目の Hello が来る
- `messages_sent_while_offline_are_dropped_not_blocking`: 未接続中に from_mcp に入れても run が詰まらない

## 実装

- 接続 → Hello 送信 → 送受信ループ。切断されたら backoff を倍にして再接続、成功したら initial に戻す
- `Error` を受けたら stderr に出して切断扱い
- 未接続時の Reply は捨てて stderr に 1 行（本文は出さない）
- main.rs: 環境変数がそろえば `ws::run` を spawn し、stdio と mpsc でつなぐ
