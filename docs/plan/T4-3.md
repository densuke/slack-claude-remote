# T4-3 slash command と interactions

- モデル: sonnet
- 依存: T0-2
- 参照: spec §5.4、§5.5、§6.4、§13
- 変更ファイル: `crates/relay/src/slack/commands.rs`、`crates/relay/src/slack/commands/tests.rs`、`crates/relay/src/slack/interactions.rs`、`crates/relay/src/slack/interactions/tests.rs`、`crates/relay/src/slack/mod.rs`

## 公開 API

```rust
// commands.rs
#[derive(Debug, PartialEq)]
pub enum Cmd { Pick, List, Unbind, Help }
pub fn parse(text: &str) -> Cmd;                    // "", "list", "unbind", other → Help
pub fn pick_response(names: &[String]) -> serde_json::Value;   // ephemeral body with static_select
pub fn text_response(text: &str) -> serde_json::Value;         // {"response_type":"ephemeral","text":...}

// interactions.rs
#[derive(Debug, PartialEq)]
pub struct Selection { pub session: String, pub channel: String, pub user: String, pub response_url: String }
pub fn selected_session(payload: &serde_json::Value) -> Option<Selection>;
```

## テスト（先に書く）

- `empty_is_pick`、`whitespace_is_pick`
- `list_and_unbind_parsed`（前後空白、大文字も受ける）
- `unknown_is_help`
- `pick_response_has_static_select`: `response_type == "ephemeral"`、`action_id == "sccr_select"`、option の value が session 名
- `pick_response_empty_is_text_only`: セッション 0 件なら blocks なしで spec §13 の文言
- `block_actions_extracts_selection`
- `other_action_id_ignored`
- `non_block_actions_ignored`

## 実装

- Block Kit は `serde_json::json!` で組む
- option の text は 75 文字で切る（Slack の制限）
