## 公開 API

```rust
// hub.rs
pub struct Hub; // RwLock<HashMap<String, mpsc::Sender<RelayMsg>>>
impl Hub {
    pub async fn register(&self, name: &str, tx: mpsc::Sender<RelayMsg>) -> Result<(), Duplicate>;
    pub async fn unregister(&self, name: &str);
    pub async fn list(&self) -> Vec<String>;             // sorted
    pub async fn send(&self, name: &str, msg: RelayMsg) -> Result<(), Offline>;
}

// store.rs
#[derive(Serialize, Deserialize, Default)]
pub struct Store { pub users: Vec<String>, pub tokens: Vec<TokenRecord>, pub bindings: BTreeMap<String, Binding> }
impl Store {
    pub fn load(path: &Path) -> io::Result<Store>;       // missing file -> Default
    pub fn save(&self, path: &Path) -> io::Result<()>;   // tmp + rename
    pub fn token_ok(&self, raw: &str) -> bool;           // sha256 compare
}

// slack/api.rs
#[async_trait]
pub trait SlackApi: Send + Sync {
    async fn post_message(&self, channel: &str, thread_ts: Option<&str>, text: &str) -> Result<String, SlackError>; // returns ts
    async fn respond(&self, response_url: &str, text: &str) -> Result<(), SlackError>;
}
pub struct HttpSlack;   // reqwest, chat.postMessage
pub struct LogSlack;    // SCCR_DEV: print to stdout, return fake ts
pub struct FakeSlack;   // pub, records calls in Mutex<Vec<Call>>; used by tests and e2e

// config.rs
pub struct Config { bind, public_url, state_file, admin_user, signing_secret, bot_token, client_id, client_secret, dev: bool }
pub fn from_env() -> Result<Config, String>;  // not unit-tested (thin)

// state.rs
pub struct AppState {
    pub cfg: Config, pub hub: Hub, pub store: Mutex<Store>, pub slack: Arc<dyn SlackApi>,
    pub dedupe: Mutex<Dedupe>, pub pending: Mutex<HashMap<String, Pending>>, pub now: fn() -> i64,
}

// routes.rs
pub fn router(state: Arc<AppState>) -> axum::Router;
```

`pending` は T6-2 で使う。型だけ先に置く（`Pending { chat_id, session, created }`）。
`auth` 系ルートは T5-2 で追加する。

## 実装要点

- events: body をバイト列で取得 → 署名検証 → classify → `url_verification` なら即応答 → それ以外は `tokio::spawn` で処理して即 200
- テストでの非同期処理待ちは、FakeSlack の記録または rx を `tokio::time::timeout(1s)` で待つ
- `/agent/ws`: Bearer → `store.token_ok`（dev なら `dev` も可）→ upgrade → 最初のフレームが Hello でなければ Error → hub 登録（重複なら Error）→ `Welcome` → ループ。切断で unregister
- Reply: chat_id を最初の `:` で分割 → `chunk::chunk(text, 3900)` → 順に post_message
- main.rs: `from_env` → `Store::load` → `HttpSlack` または `LogSlack` → `axum::serve`
