# T3-2 手動スモーク（Claude Code 実機）

- モデル: opus（人の操作を伴う）
- 依存: T3-1、T4-4

## 手順

1. `SCCR_DEV=1 cargo run -p sccr-relay`
2. `cargo build -p sccr-agent`
3. 登録:
   `claude mcp add sccr -e SCCR_RELAY_URL=ws://127.0.0.1:8080/agent/ws -e SCCR_TOKEN=dev -e SCCR_SESSION_NAME=smoke -- $(pwd)/target/debug/sccr-agent`
4. 別ターミナルで `claude --dangerously-load-development-channels server:sccr`
5. `curl -X POST localhost:8080/dev/inject -H 'content-type: application/json' -d '{"session":"smoke","chat_id":"C1:1.1","user":"U1","text":"say hi"}'`
6. relay の stdout に `chat_id=C1:1.1` の投稿が出ることを確認
7. ファイル書き込みを頼み、権限要求が relay に届くことを確認

## 確認項目
