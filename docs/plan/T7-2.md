# T7-2 実機 E2E

- モデル: opus（人の操作を伴う）
- 依存: T7-1、e2 と Slack アプリの準備

## 手順

1. e2 に relay を配置し、`https://<host>/healthz` が 200
2. Slack で Event Subscriptions の URL 検証が通る
3. ブラウザでログイン、トークン発行
4. Mac で agent を登録し、Claude Code を channels 付きで起動
5. Slack のチャンネルで `/cc` → セッション選択 → root 投稿
6. スレッドで質問 → Claude の返答がスレッドに出る
7. ファイル作成やコマンド実行を頼む → 権限プロンプト → `yes xxxxx` で実行される
8. relay のログで、3 秒以内の応答と重複処理がないことを確認（本文がログに出ていないことも確認）
