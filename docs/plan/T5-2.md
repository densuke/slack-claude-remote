## ルート

- `GET /login`: `Sessions::begin` → 302 authorize_url
- `GET /auth/callback?code&state`: pending 取得（無ければ 401）→ `oidc.token` → `parse_id_token`（失敗 401）→
  `sub != admin_user` なら 403 → users に追加して保存 → Cookie `sccr_sid`（HttpOnly; Secure; SameSite=Lax; Path=/）→ 302 `/`
- `GET /`: Cookie 無効なら 302 `/login`。有効なら接続中セッション一覧、トークン発行フォーム、発行済みラベル一覧
- `POST /tokens`（form `label`）: Cookie 必須（無効は 302 `/login`）→ `random_token` → sha256 を保存 → 平文を 1 回だけ表示
- HTML 出力の値はすべてエスケープ（`&<>"'`）
