## 公開 API

```rust
pub fn chunk(text: &str, max_chars: usize) -> Vec<String>;
```

- 文字数（`char` 単位）で数える
- max 以内なら 1 個
- 超える場合、max 以内で最後の改行の直後で切る。改行が無ければ max 文字で切る
- 空文字は `vec![""]`（呼び出し側で空投稿を避けるため、そのまま返す）
